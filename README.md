# Water Quality Analysis Hackathon Project

## Overview
This project builds a machine learning pipeline to classify Indian river water samples as safe or polluted.

## Dataset
- `water_dataX.csv` → Automatically downloaded in the notebook from this repository.

## Notebook
- `Hackathon_WaterQuality.ipynb` → Open in Google Colab and click **Run all**.
- No manual uploads required — dataset is auto-fetched.

## Results
- Logistic Regression Accuracy: ~86%
- Random Forest Accuracy: 100%
- Key predictors: BOD, Fecal Coliform

## Deliverables
- Notebook (`.ipynb`)
- Dataset (`water_dataX.csv`)
- Predictions (`submission.csv`)

1. Open the notebook in Google Colab.
2. Click **Run all**.
